# Разведка незнакомой базы Заботы

Набор SQL-скриптов: за один проход по клиентской базе получить карту и понять,
куда копать. Нужны только права на чтение, данные не меняются.

## Порядок

| № | Скрипт | Что даёт |
|---|---|---|
| 01 | `01_schema_map.sql` | таблицы: строки, размер, даты создания; сводка по базе |
| 02 | `02_object_inventory.sql` | список всех объектов + волны создания по месяцам |
| 03 | `03_find_by_name.sql` | поиск по именам, колонкам и **коду** вьюх/процедур (главный скрипт) |
| 04 | `04_table_shape.sql` | всё про одну таблицу: колонки, индексы, связи, кто читает |
| 05 | `05_live_tables.sql` | какие таблицы реально живут, а какие мёртвый кастом |
| 06 | `06_who_uses.sql` | кто ссылается на объект (точные зависимости + текст кода) |
| 07 | `07_deliveries.sql` | сценарии рассылок и их условия отбора |
| 08 | `08_delivery_detail.sql` | один сценарий целиком: отбор, параметры, «соседи» |

Типовой заход: **01 → 02 → 03**. Дальше 04–06 по найденному, 07–08 если задача
про рассылки.

## Как запускать

Открыть в SSMS (или PR2), вписать параметры в начале скрипта (`@Table`, `@Obj`,
`@DeliveryID`, список слов в 03), выполнить. Результат скопировать в чат как есть.

## Поиск кастома сравнением с эталоном

1. Открыть чистую базу (`wellness_new`), выполнить `02_object_inventory.sql`,
   сохранить список в файл `sterile.txt`.
2. На клиенте — то же самое, сохранить в `client.txt`.
3. Сравнить:

```bash
python tools/schema_diff.py sterile.txt client.txt
```

Выдаст два списка: что есть только у клиента (кастом) и что есть только в
эталоне (другая версия). Это и есть «куча новых таблиц», только в явном виде.

## Права

Всё работает под `db_datareader`. Единственное исключение — блок активности в
`05_live_tables.sql`, ему нужно `VIEW DATABASE STATE`; без него он просто
сообщит и пропустится.

## Что сохранять

Результаты по клинике — в `docs/zabota/clients/<Zabota_ID>/`:

- `schema-map.md` — выжимка: что за кастом, как связан, кто использует;
- `inventory.txt` — сырой список объектов;
- вывод 03/07 по конкретной задаче.
