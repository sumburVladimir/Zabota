# Teamly — база знаний компании

Источник: `https://zabota.teamly.ru/home/my` (TEAMLY, платформа QSOFT).
Дата снятия структуры: 13.11.2026.

## Доступ

- Отдельного API-токена у нас **нет**. Пользователь входит в Teamly вручную
  во встроенном браузере OpenCode; сессия живёт в профиле приложения.
- SPA Teamly работает поверх внутреннего JSON API `https://app2.teamly.ru/api/v1/...`.
  Из залогиненной вкладки его можно вызывать обычным `fetch`, ключевое:
  - `credentials: 'include'` (cookie-сессия),
  - заголовок `x-account-slug: zabota`,
  - `Content-Type: application/json`.
  Без `x-account-slug` приходит `401 unauthorized`.
- Публичного/документированного API у Teamly для этого контура не выдавали,
  поэтому всё, что ниже, — **реверс запросов самой панели**. Эндпоинты могут
  поменяться без предупреждения.

## Эндпоинты, которые использует панель

| Что | Запрос |
|---|---|
| Текущий пользователь | `GET /api/v1/me` |
| Список пространств | `POST /api/v1/wiki/ql/spaces` |
| Список статей | `POST /api/v1/wiki/ql/articles` |
| Статья целиком | `GET /api/v1/wiki/articles/{id}?viewMode=edit&latestVersionAt=1` |
| Блоки/вложенные статьи | `POST /api/v1/wiki/ql/article_content` |
| Путь в дереве | `POST /api/v1/wiki/ql/tree_to_article` |
| Комментарии | `GET /api/v1/space/{spaceId}/article/{articleId}/comments` |

Формат `ql`-запросов (query builder):

```json
{
  "query": {
    "__filter": { "space_id": "<uuid>" },
    "__pagination": { "page": 1, "per_page": 50 },
    "__sort": null,
    "id": true, "title": true, "containerId": true,
    "space": { "id": true, "title": true },
    "published_at": true
  }
}
```

- `per_page` максимум **50** (иначе 422).
- Общее число статей приходит в `paginate.total`.
- **Важно:** фильтр по пространству в `/ql/articles` на `total` не влияет —
  считать статьи надо по фактически возвращённым записям, а не по `total`.

### Формат контента

Тело статьи лежит в `editorContentObject.content` — это **JSON-строка**
документа ProseMirror (`{"type":"doc","content":[...]}`): `heading`, `paragraph`,
`bulletList`, `orderedList`, `blockquote`, `codeBlock`, `table`, `image`,
`text` с `marks` (bold/italic/link). Конвертируется в markdown обходом дерева.

## Выгрузка в документацию — сделано

Вся база выгружена в **`docs/zabota/teamly/`**: 26 пространств, **945 статей**,
~3,6 МБ markdown. Индекс — `docs/zabota/teamly/README.md`.

Как это работает (скрипты в `.opencode/skills/teamly/scripts/`):

1. `collector.py` — локальный HTTP-приёмник на `127.0.0.1:8765`:
   `POST /save` пишет markdown в `docs/zabota/teamly/`, `GET /raw/crawl.js`
   раздаёт скрипт, `GET /stats` — счётчики.
2. `crawl.js` — выполняется в залогиненной вкладке Teamly: забирает список
   статей, тянет тела, конвертирует ProseMirror → markdown и постит в приёмник.
   4 параллельных воркера, весь прогон ~50 секунд.
3. `make_index.py` — собирает `README.md` по frontmatter файлов.

Запуск: см. скилл `.opencode/skills/teamly/SKILL.md`.

Итог прогона: 956 обработано, 945 сохранено, 11 ошибок — главные страницы
пространств без контента (отдают 404).

Ограничения: вложения и картинки не переносятся как файлы — остаются ссылками
на Teamly; при пересоздании статьи ссылки могут протухнуть.
