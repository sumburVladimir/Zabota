# Карты клиник

Одна папка на клинику: `docs/zabota/clients/<Zabota_ID>/`.

Что складываем:

- `schema-map.md` — карта базы: кастомные таблицы/вьюхи, как связаны, кто
  использует, чем отличается от эталона. То, что дороже всего добывать заново.
- `inventory.txt` — сырой вывод `02_object_inventory.sql` по этой клинике.
- `tasks/<ID Битрикса>.md` — разбор конкретной задачи: что смотрели, что нашли,
  что сделали.

Шаблон `schema-map.md`:

```markdown
# Клиника <ID> — <название>

| Что | Значение |

| Zabota_ID | |

| Версия серверной части | |
```
