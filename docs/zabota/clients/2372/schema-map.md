## Кастомные таблицы и функции

| Объект | Тип | Назначение и особенности |
|---|---|---|
| `dbo._custom_patients` | таблица | Доп. флаги пациента: `not_notify_actions`, `not_notify_invites` (`= 0` — разрешено слать). Обязательный `INNER JOIN` в СОЗах. |
| `dbo._custom_visits_directions` | таблица | Справочник направлений визитов (`id`, `Name`) из МЕДИАЛОГ (`PL_EXAM`). В `patients_visits` хранится в колонке `_custom_visit_direction_id`. |
| `dbo._visits_directions` | таблица | Привязка направлений к группам (`direction_id`, `group_id`). **Подводный камень:** новые направления из МИС (например `2118`) могут иметь `group_id IS NULL`, поэтому `INNER JOIN _visits_directions vd ON ... AND vd.group_id = 1` отсекает такие визиты. |
| `dbo.ftGlossary('chairs', 1)` | табличная функция | Возвращает `item_id` кабинетов/специальностей (`v.chid` / `PL_SUBJ_ID`), включённых в группу `1`. **Подводный камень:** новые врачи/кабинеты (например офтальмолог `chid = 61`) туда не добавлены автоматически -> отбор с `ftGlossary('chairs', 1)` возвращает 0 строк. |
| `dbo.doctorx` | таблица | Привязка `doctor_id` к `group_id` (группы врачей 1..4) для `dbo.fsIsFirstToDoctorsByGroup(appoint_id, group_id)`. |
| `dbo.VisitsPerDay(patient_id, date)` | скалярная функция | Склейка визитов пациента за день, вызывается в `SELECT` всех основных СОЗов. |

## Как устроены СОЗы (Сообщения о записи)

В базе используется связка «родитель (`dactive = 0`, держит `Uni_key` на `deliv_conditions`) -> дочерний сценарий (`Parent_id`, `dactive = 1`, `Uni_key = NULL`)»:

- **Общие врачебные СОЗы:**
  - `276` («Сообщения о записи на прием первый раз к врачу», родитель `275`)
  - `756` («Сообщения о записи на прием первый раз в клинику», родитель `755`)
  - Оба сидят на **одном общем условии `cond_id = 1`** (`Uni_key = 7381432839807828091`, «1.Сообщение о записи на прием впервые»).
- **Процедурные СОЗы:**
  - `673` (спермограмма, род. `672`), `676` (УЗИ-скрининг, род. `675`), `678` (УЗИ моч. пуз., род. `677`), `680` (УЗИ ОБП, род. `679`), `682` (ТРУЗИ, род. `681`), `684` (кольпоскопия, род. `683`), `814` (эякулят, род. `813`)
  - Все 7 сидят на **одном общем условии `cond_id = 267`** (`Uni_key = 7400833704595947784`, «1.5 Сообщение о записи по процедурам», фильтр по `:RVISIT` -> `_custom_visit_direction_id`).
