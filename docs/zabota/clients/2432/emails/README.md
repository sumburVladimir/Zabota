## Что внутри шаблона

- карточка 600 px на сером фоне `#f3f4f6`, скругление 16 px, рамка `#e5e7eb`;
- шапка: логотип `ELIXIR ESTATE` (изображение с `companies.zabota.space`), ссылка на сайт;
- структура текста: «Здравствуйте!» → лид-абзац (жирный) → абзацы текста →
  закрывающий абзац с призывом;
- блок промокода: серая плашка, код крупно, условия мелким серым;
- кнопка «Запишитесь на консультацию» (`#2563eb`), ссылка — псевдоним `{ref3}`
  (PR2 сам подставляет персональную ссылку);
- строка «Подробнее об услуге» со ссылкой на страницу услуги на сайте клиники;
- подвал: телефон `{cpn}`, адрес `{car}`, сайт `elixe-samara.ru`;
- юридический блок + `отписаться от рассылки` → `[%unsubscribe_link%]`;
- прехедер скрытым блоком в начале `<body>`.

## Псевдонимы

Используются только стандартные: `{ref3}` (заявка/запись), `{cpn}` (телефон),
`{car}` (адрес). Тема письма в PR2 задаётся отдельным полем, не в HTML.

## На что обратить внимание при загрузке

1. Кодировку не менять — файлы уже в CP1251; открывать в Notepad++ как ANSI,
   иначе сохранение в UTF-8 сломает кириллицу.
2. Кнопка ведёт на `{ref3}` (индивидуальная ссылка на заявку). Если для
   маркетинговой рассылки нужна прямая ссылка на сайт — заменить `href` у
   кнопки на нужный URL.
3. Логотип зашит ссылкой
   `https://companies.zabota.space/storage/logos/logo_%20EX.png` (пробел
   в имени файла закодирован как `%20`), ширина 280 px, кликабельный → сайт
   клиники. Хостинг Заботы должен быть доступен получателям; если картинка
   не отображается — заменить `src` на свой хостинг.
4. Загружать в PR2 через кнопку «Загрузить шаблон» в канале Email сценария,
   по одному файлу на сценарий (email нельзя ставить в каскад).
