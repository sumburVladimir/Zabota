## Правила работы с этой папкой

1. **Не распаковывать архивы** (`.7z`, `.zip`, `.rar`) без необходимости.
2. **Не читать `пароли.txt`** и не переносить секреты в документацию.
3. `.log`, `.csv`, `.sql`-дампы — источник фактов, но не читать целиком:
   сначала `grep` по нужному шаблону.
4. Из каждой прочитанной пачки делать выжимку в `docs/zabota/`, чтобы не
   зависеть от контекста сессии.
5. Тяжёлые разделы разбирать пакетами, по одному разделу за раз.
