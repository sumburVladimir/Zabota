# Инструкции для папки `интеграция`

Это личная база знаний пользователя (2 921 файл, ~3.9 ГБ), а не часть продукта.

- Навигация: `README.md`, `inventory.csv`, `notes-index.md`, `digest-*.md`.
- Не читать `пароли.txt`, `.log`, `.csv` и `.sql`-дампы целиком.
- Не распаковывать архивы `.7z` / `.zip` / `.rar` без явной просьбы.
- Большие файлы искать через `grep`, а не читать подряд.
- Результат разбора писать в `digest-*.md` в этой же папке.
